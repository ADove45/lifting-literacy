Add it to your website

Step by step.

Menu names can differ slightly between versions.

WordPress

  1. Go to Pages, then Add New. Name the page #LiftingLiteracy.

  2. Click the plus button to add a block and choose Custom HTML.

  3. Paste the page code.

  4. Replace the three items in brackets.

  5. Click Publish.

Squarespace

  1. Add a new blank page.

  2. Edit the page, click Add Block and choose Code.

  3. Click the pencil icon, delete the sample text and paste the page code.

  4. Replace the three items in brackets.

  5. Save.

No Code block? Use the plain text.

Wix

  1. Add a new page.

  2. Click Add Elements, then Embed Code, then Embed HTML.

  3. Click Enter Code, paste the page code and click Apply.

  4. Wix shows pasted code in a fixed-size box. Drag its edges until the whole page shows.

  5. Replace the three items in brackets, then Publish.

The plain text is often simpler on Wix.
